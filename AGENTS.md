# AGENTS.md

## Keep TODO.md current

`TODO.md` is the source of truth for ShareX Extended wishes. After any code change, check whether it touches an item there and update that item's status and evidence in the same change set (see the `sharex-todo-audit` skill). Never assume a status is stale: verify the code before changing it.

When reconciling with `TODO.txt` or auditing all items, use the `sharex-todo-audit` skill.
